## Installation

### Firefox

#### Add-on Store (Recommended)

[Add-on Store page](https://addons.mozilla.org/en-CA/android/addon/youtube-notification-expander/) Click Add to Firefox, then click Add. Done. 

#### Manual installation via .xpi from Add-on Store (less recommended)

Access the [Add-on Store page](https://addons.mozilla.org/en-CA/android/addon/youtube-notification-expander/), then right-click the Add to Firefox button and click Save Link As... Then click Save. Drag the downloaded .xpi file to the tab bar of Firefox. Click Add. Done. \

#### Manual installation via .xpi from GitHub (less recommended)

Access the [Releases](https://github.com/Diode-exe/youtubeNotificationBell/releases) page. Click the latest release, then download the .xpi file. Drag the downloaded .xpi file to the tab bar of Firefox. Click Add. Done. 

#### Manual installation via source code (not recommended)

You can download the latest version from Releases. After downloading, unzip the .zip file, go to `about:debugging` in Firefox, click "This Firefox", then "Load Temporary Add-on", and select the `manifest.json` file from .zip/firefox/manifest.json. 

### Tampermonkey

Tampermonkey installation is also available. You can download the latest version from Releases. After downloading, unzip the .zip file, go to your Tampermonkey dashboard, click "Utilities", then "Import", and select the `main.js` file from .zip/tampermonkey/main.js.
